★ The Core Architecture ★

One Housing.
Many Modules.

The Universal Modular Housing is the shared backbone of the range — a single backplate and outer housing architecture that accepts interchangeable inserts, so one product family can cover sockets, switches, USB outlets and controls.

One backplate. One outer housing. Any function you need.

What It Is
The shared foundation for the whole range.

Rather than designing a separate housing for every switch, socket or control, the Universal Modular Housing provides one fixed outer shell and mounting system. Function is determined by which insert is fitted inside it, not by the housing itself.

How It Works
Backplate, insert, outer housing.

The backplate mounts to the vehicle surface and provides the fixing points. A functional insert — socket, switch, USB module or blank — sits inside it. The outer housing closes over both using the standard Electrasthetics closure system, holding everything flush and concealed.

Interchangeable Inserts
One housing, several functions.

The same outer housing and backplate accept a range of inserts, so installers can standardise on one product family rather than stocking a different housing for every function.

01

Round Socket Insert

Accepts standard round 12V/24V accessory sockets in the shared housing profile.

02

USB Module Insert

Single or dual USB-A/USB-C charging modules fitted in the same footprint.

03

Rocker Switch Insert

Standard rocker switch profile for lighting, pumps and other on/off circuits.

04

Push Button Insert

Momentary and latching push buttons for smart control and accessory functions.

05

Blank Insert

A plain cover for positions reserved for future expansion, keeping the run visually complete.

06

Mixed-Module Panel

Larger housings can combine several insert types in one coordinated panel.

Commercial Value
Fewer tools to design, more products to sell.

A shared architecture reduces development effort for every new product added to the range, while giving customers a reason to standardise on Electrasthetics across their whole installation.

A

Lower Development Cost

New functions can often be met with a new insert rather than a new housing design.

B

Simplified Stocking

Installers and retailers can hold one housing and a range of inserts rather than many complete products.

C

Future-Proofing

New insert types can be introduced later without changing the housing customers have already fitted.

The housing is the platform. Everything else plugs into it.
