The Router.
No Longer On Display.

A coordinated housing for the Wi-Fi router or comms equipment nearly every modern conversion now includes — hiding cabling and status lights behind a finish that matches the rest of the installation, instead of leaving a bare consumer router sitting on a shelf.

Electrasthetics router housing

Connectivity is now standard. A tidy way to house it still isn't.

What It Is
A coordinated home for the router customers already own.

Rather than a bare consumer router sitting on an open shelf, this housing gives it a proper fixed position — cables routed and concealed, status lights visible where needed, finished in the same Electrasthetics colour range as everything else.

Why It's Needed
Connectivity is now a standard build item.

Mobile routers, 4G/5G units and Wi-Fi extenders are now a normal part of most conversions, but there's rarely a dedicated, tidy place to mount them — they end up wedged into a cupboard or left loose on a shelf.

Key Considerations
Built around how routers actually need to sit.
01

Ventilation

Routers generate heat in normal use — the housing needs to allow airflow, not seal it in.

02

Cable Routing

Power and antenna cabling routed cleanly in, using the same cable-management approach as the rest of the range.

03

Status Visibility

Signal and status indicator lights stay visible or accessible, rather than fully hidden from view.

Commercial Value
Every connected van needs somewhere for this to live.

B

Most routers are currently just placed somewhere convenient, with no proper mounting solution offered.

C

Part of the Coordinated System
